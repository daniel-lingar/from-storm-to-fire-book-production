# Archived: From the Storm to the Fire book-production workspace

This repository is an **archived historical production workspace** for *From the Storm to the Fire*. It contains manuscript chapter copies, revision backups, build scripts, design assets, and export workflow materials. Its substantive manuscript content has been reviewed and is already represented in the compiled canonical memoir repository.

## Canonical repository

The canonical public memoir is maintained at:

- [`from-the-storm-to-the-fire`](https://github.com/daniel-lingar/from-the-storm-to-the-fire)

Use the canonical repository for the current compiled manuscript and public-facing memoir materials. This repository is retained for historical revision provenance only and is not an active source of truth.

No files in this repository were deleted as part of archival. The archive action changes repository status only after this pointer README is committed and pushed.
